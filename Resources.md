## Vibecoding tips

- Make a full fledged ***PRD***.
- From PRD, wire and ***design flows*** for UI/UX and use empty, loading, error, success states.
- Cleanup and refactor ***dead code***.
- Set ***OG imgs*** for social previews and ***metadata***.
- Create ***sitemap.xml*** and do google thing and add ***404***.

  ### Security Tips
- ***Audit app*** like security engineers, find auth flaws, exposed secrets, missing rate limits, injections risks, api routes etc and give proper fix suggestion.
- ***Cross site scripting for inputs:*** Sanatise all inputs.
- ***File uploads:*** Check file type and size and prevent zip files from being uploaded.
- Enable ***row level security*** for Databases.
- Check ***logged in*** user owns data before handing data.
- Keep ***admin key*** server side
